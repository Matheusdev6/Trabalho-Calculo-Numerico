# Trabalho Cálculo Numérico

## Descrição
- Esse repositório é sobre o trabalho da disciplina de Cálculo Numérico.
- O tema que vamos escolher é Regressão Linear, vamos resolver algum problema com o método numérico apresentado em sala.

## Tecnologias
- Python
- matplotlib (plotagem de gráficos)
- numpy (funções para algumas operações)

## Como rodar
- Certifique-se de ter o Python 3.14.7 instalado.
- Verifique se o pip está instalado, para instalar as bibliotecas necessárias.
- Clone o repositório, com o comando
> git clone https://github.com/Matheusdev6/Trabalho-Calculo-Numerico.git
- Crie um ambiente virtual (venv), com o comando
> python3.14.7 -m venv (nome da pasta)
- Instale as bilbiotecas com os comandos
> pip install numpy 
> pip install matplotlib
